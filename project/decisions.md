# Decisiones del proyecto

Todavía no hay decisiones de producto. Los acuerdos base están en `../harness/stack.md`.

Agregar entradas cuando cambien alcance, flujos, dirección visual, tecnología o integración. Conservar el historial; una decisión posterior puede reemplazar otra.

- Impacto y entregables por revisar:
- Cómo verificar el resultado:
